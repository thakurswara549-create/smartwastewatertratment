All project components — labelled reference list

Use these identifiers consistently in your website, report, block diagram and viva explanation.

U1
ESP32 DevKit V1

Main controller for sensor reading and control logic.

S1
pH probe / interface

Measures acidity or alkalinity; requires a compatible signal-conditioning board.

S2
Temperature sensor

Monitors wastewater temperature.

S3
Turbidity sensor

Indicates water cloudiness before/after filtration.

S4
TDS sensor

Estimates total dissolved solids; ordinary sand filtration may not remove dissolved salts.

S5
Level sensor

Monitors tank fill level and can support overflow/dry-run interlocks.

S6
Flow sensor

Measures flow in a compatible transfer pipe.

T1–T4
Four tanks / vessels

Inlet, neutralization, conventional filter housing and treated-water tank.

P1
Transfer pump 1

Inlet tank to neutralization tank.

P2
Transfer pump 2

Neutralization tank to filter unit.

P3
Transfer pump 3

Filter unit to treated-water tank.

DP-A
Acid dosing pump

Represents acid dosing when pH is above the control target.

DP-B
Base dosing pump

Represents base dosing when pH is below the control target.

M1
Mixer / stirrer

Mixes wastewater during neutralization.

F1
Conventional filter media

Illustrative sand/gravel or selected filter media bed.

DR1
Relay / motor driver

Interfaces controller signals to rated loads; motors must not be driven directly by ESP32 GPIO.

PS1
Regulated DC supply / SMPS

Supply must match controller, sensors, pumps and motor requirements.

L1
Pipes, valves, fittings

Connect tanks and direct the water path.

1. Set sensor values manually

Change the values to test different wastewater conditions. Click Apply values before starting the process.

Control rule: pH below 6.5 → represent base dosing (DP-B). pH above 8.5 → represent acid dosing (DP-A). Within 6.5–8.5 → dosing off. Mixer runs during the neutralization step.

Viva explanation

The ESP32 is the proposed controller. It reads water-quality and level sensors, uses the pH reading to select a dosing response, and operates transfer pumps and the mixer through suitable driver circuits. Filtration is represented as a separate treatment stage.

Educational concept simulation · No real sensor data, chemical dosing calculation, or discharge-compliance test is performed.
